## About the course

This programme takes a practising Green Belt to Black Belt. DMAIC is recapped in depth — a Black Belt has to be able to mentor Green Belts through every tool — and then extended with the analysis a Green Belt course does not cover: attribute MSA and Kappa, nested and destructive gauge studies, non-normal capability, multiple regression with model diagnostics, ANOVA with interactions, multi-vari studies, full and fractional factorial design of experiments, response surface methods, and CUSUM, EWMA, short-run and multivariate SPC.

It is built around one continuous capstone project rather than a set of disconnected exercises. Every lab adds one artifact to that project, and Day 5 consolidates them into an A3 storyboard and a steering committee presentation.

## Learning outcomes

- Lead a Lean Six Sigma project portfolio — select, charter and govern projects aligned to business strategy (A1, A2).
- Validate measurement systems for continuous AND attribute data using Gage R&R and Kappa analysis (A4).
- Analyse process data using multiple regression, ANOVA, non-parametric tests and multi-vari studies (A3).
- Design, run and interpret experiments using full and fractional factorial DOE and response surface methods (A3, K2).
- Select, de-risk and pilot improvements, and validate financial benefits with Finance sign-off (A5).
- Sustain the gain using advanced SPC — CUSUM, EWMA, short-run and multivariate control charts (A5, K1).
- Lead change and mentor Green Belts through resistance, stakeholder management and tollgate governance (A1, K1).
- Deliver a capstone improvement project and present it to a steering committee (A1-A5, K1, K2).

## Labs

34 hands-on labs, each in its own folder under [labs/](labs/). Every lab folder is a complete activity pack:

| File | What it is |
|---|---|
| `README.md` | The activity brief — scenario, evidence, step-by-step, self-check |
| `scenario.md` | The case study on its own, for printing or projection |
| `worksheet.md` / `.pdf` | Blank team worksheet to complete in class |
| `debrief.md` / `.pdf` | Trainer debrief — expected analysis and teaching points |
| `prompt.txt` | A GenAI prompt for the activity |
| `*.xlsx` | The lab data — a dataset to analyse, or a structured template |

The datasets describe one continuous process (a medical-device seal weld line), so figures reconcile from lab to lab: the baseline capability established in Lab 14 is the same baseline the control charts in Lab 27 improve on, and the benefit validated in Lab 30 reconciles to the cost of poor quality chartered in Lab 1. Every workbook opens on a Data Dictionary sheet defining each column, its unit and the specification limits.

Learners are encouraged to substitute their own workplace data wherever they can obtain it; the workbooks are the fallback.
